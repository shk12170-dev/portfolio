# 대상과 공개 범위 (2026-11-11 개정)

**한 문장:** 이 페이지는 네트워크 보안·보안관제 직무 채용 담당자에게, 내가 보안관제망을 구성하고 공격 탐지·자동 대응·원복을 실측한 과정을 근거와 한계까지 함께 보여주는 취업용 포트폴리오다.

## 공개한 것
1. 실명(김상혁), 연락용 이메일, GitHub 주소
2. ALEPH 팀 프로젝트: 구성, 사용 도구와 버전, 케이스별 실측 수치, 내가 맡은 일, 끝내지 못한 것
3. 팀원 이름 4명 — 최종 발표 자료 표지에 공개된 범위
4. 개인 케이스 S7: 설계, 확인한 것과 미시험 항목
5. 개인 프로젝트 nobugs-soar(공개 저장소): 팀 버전과의 차이, 반복 측정 결과, 찾아 고친 문제, 범위 밖 항목, 제어판 화면 1장(루프백 주소·시험 계정만 보임)
6. 경력(농구선수, 병사·부사관 복무, 교육과정)

3. 팀 VPN 내부 주소, 실제 학원망 주소
